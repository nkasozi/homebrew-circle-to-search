# homebrew-circle-to-search

A [Homebrew](https://brew.sh) tap for [Circle to Search PC](https://github.com/nkasozi/circle-to-search-pc) — a macOS app that brings Google Lens-style search to your desktop. Draw a circle (or select any screen region) and instantly search with Google Lens, without leaving what you're doing.

## Requirements

- macOS (Apple Silicon / ARM64)
- [Homebrew](https://brew.sh)

## Installation

Add this tap and install the cask:

```sh
brew tap nkasozi/circle-to-search
brew install --cask circle-to-search-pc
```

Or install in a single command:

```sh
brew install --cask nkasozi/circle-to-search/circle-to-search-pc
```

## Updating

```sh
brew upgrade --cask circle-to-search-pc
```

## Uninstalling

```sh
brew uninstall --cask circle-to-search-pc
```

To also remove all leftover files (preferences, caches, app support data):

```sh
brew zap --cask circle-to-search-pc
```

## About the App

Circle to Search PC lets you select any region of your screen and perform a Google Lens search instantly. It is inspired by the Android "Circle to Search" feature and brings the same experience to macOS.

- **Homepage / source:** <https://github.com/nkasozi/circle-to-search-pc>
